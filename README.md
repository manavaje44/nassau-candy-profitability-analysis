# Nassau Candy Profitability Dashboard

## Objective
Analyze product profitability, gross margins, division performance, and profit concentration for Nassau Candy Distributor.

## Features
- KPI Dashboard
- Product Profitability Analysis
- Division Performance Analysis
- Cost vs Sales Diagnostics
- Margin Risk Detection
- Pareto Analysis
- Interactive Filters

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Run Application

python -m streamlit run app.py
